Welcome to Weather Fetch.

This Website requests permission for location and sends API requests to Open Meteo for weather information and a separate request to bigdatacloud.net for displaying the location. To display Time, the built-in JS features such as setInterval & timeString are used. 

The stickers are taken from pinterest, and the styling is normal CSS.

A few animations are also beautifully put in to induce the sense of interactivity, bringing together a good website for knowing the weather.

You can try it out on =>  https://weather-fetch-six.vercel.app/
